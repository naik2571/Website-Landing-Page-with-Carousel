# Naik Zari Art - Web Portfolio 🎨

A specialized, highly responsive web platform and landing page developed for an independent art brand. This project serves as a digital storefront and portfolio, designed to elegantly showcase the brand's intricate artwork and increase user engagement through interactive UI elements.

## ✨ Key Features

* **Custom CSS Carousels:** Interactive image sliders built from scratch to showcase the brand's art portfolio without relying on heavy external libraries.
* **Responsive Design:** Fluid layouts utilizing Flexbox and CSS Grid to ensure the website looks beautiful on desktops, tablets, and mobile devices.
* **Optimized Performance:** Lightweight HTML and CSS architecture resulting in extremely fast page load times and smooth scrolling.
* **Modern UI/UX:** Clean, elegant design tailored specifically for an art brand, emphasizing high-quality imagery and typography.

## 🛠️ Technology Stack

* **Structure:** HTML5
* **Styling:** CSS3 (Custom Animations, Flexbox, Media Queries)
* **Interactivity:** Vanilla JavaScript
* **Deployment:** Hosted live for web access

## 🚀 How to Run Locally

Since this is a static frontend web project, running it locally is incredibly simple and requires no backend server!

### Installation Steps

1. **Clone the repository:**
   ```bash
   git clone https://github.com/naik2571/Naik-Zari-Art.git
   cd Naik-Zari-Art

2. **Launch the Website:**
 * Simply locate the index.html file inside the downloaded folder.
 * Double-click it to open it in your default web browser (Chrome, Edge, Safari, etc.).
 * (Optional): If you are using Visual Studio Code, you can right-click index.html and select "Open with Live Server" for hot-reloading during development.
